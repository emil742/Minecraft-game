# Minecraft-game
Beginner Java practice projects: console games, input handling, and classes.
## What it uses
- `ArrayList` to store the character list
- `Scanner` to read the player's choice
- Variables for HP, attack, and special move

## How to run
1. Install the Java JDK.
2. Run `javac Main.java`, then `java Main`.
